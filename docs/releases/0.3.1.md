# v0.3.1

## 달라진 점

- **게임 중 조작법.** 화면 위 가운데에 반투명한 조작법 패널이 뜹니다 (키 13개). `/` 키나 패널 아래의 버튼으로 숨기고 다시 펼 수 있고, 숨긴 상태는 브라우저에 기억합니다. 
- **다음에 누를 키.** 패널 아래 줄에 지금 할 만한 것을 한 줄로 알려 줍니다: 총이 걸렸으면 Space, 탄창을 꽂았으면 Space(슬라이드), 쥔 탄창이 있으면 F, 탄창이 빠졌으면 1~4, 칸이 모두 비었으면 E 로 줍기, 헛방이면 R, 적의 조준선이 보이면 S(숙이기). 화면에 보이는 상태(탄창이 꽂혔는지, 칸 · 손)와 방금 일어난 일(꽂기 · 걸림 · 헛방)로만 판단하고, 숨긴 탄 수는 쓰지 않습니다.
- **조준점.** 마우스 자리에 픽셀 조준점이 생기고, 게임 중에는 기본 커서를 숨깁니다. 쏘면 잠깐 벌어지고, 장전이나 반동으로 총이 바쁜 동안에는 흐려집니다.
- **PC 전용.** 휴대폰 · 태블릿용 터치 조작을 없애고, 화면 폭이 768px(태블릿 기준점)보다 좁으면 "넓은 화면에서 키보드와 마우스로 해 주세요" 안내로 화면 전체를 덮습니다.
- **총 리그의 좌우.** 왼쪽을 겨누면 아래의 총이 좌우로 뒤집혀 왼쪽을 봅니다. 위를 겨누면 어느 쪽이든 총구가 올라가고(전에는 왼쪽 위를 겨누면 총구가 내려갔습니다), 반동 · 탄피 · 손에 쥔 탄창도 총을 따라 뒤집힙니다.

## 고친 것

- 총을 위로 기울이면 총 리그를 그리는 영역의 위쪽에서 총이 잘렸습니다. 이제 그리는 영역을 아래 띠 높이의 두 배(화면 높이까지)로 잡고, 총과 칸의 크기는 예전처럼 아래 띠 높이로 정합니다.
- 좁은 창에서 grip 글자가 3 · 4 칸 이름과 겹쳤습니다.

## 내부 변경

- `src/client/guide.ts` 를 새로 만들었습니다 (조작법 패널 · 다음 키 안내). 문자열은 textContent 로만 넣습니다.
- 터치 버튼 · 터치 조준 · 휴대폰 전용 배치(가로 회전 안내, 휴대폰 픽셀 비율 · 시야각)를 지웠습니다. 작업 규칙(`CLAUDE.md`)의 화면 크기 기준도 데스크톱 전용으로 바꿨습니다.
- 총 리그(`src/client/rig.ts`): 총을 가운데를 축으로 돌리고 뒤집는 바깥 그룹(pivot)을 두었습니다. 입체감을 주는 회전도 이 축에서 합니다.
