# v0.3.2

## 고친 것

- 한글 입력 상태에서는 키가 먹지 않아서, 한/영을 눌러 영문으로 바꿔야 했습니다. 키를 입력된 글자(`e.key`)로 읽어서, 한글 입력 상태에서는 R 이 `ㄱ`, W 가 `ㅈ` 처럼 들어와 알아보지 못했기 때문입니다. 이제 눌린 자리(`e.code`, 예: `KeyR`)로 읽어서 입력기 · 자판 배열과 상관없이 동작합니다 (Friday Deploy 와 같은 방식). 숫자 패드의 1~4 도 탄창 쥐기로 씁니다.

## 내부 변경

- `src/client/keys.ts`: 자리(e.code) → 게임 동작 이름 표와, 브라우저 기본 동작을 막을 키 목록. `npm test` 에 화면 쪽 테스트(`src/client/*.test.ts`)를 더했습니다.

## 확인한 것

- `npm run typecheck`, `npm test`, `npm run build`
- 운영 방식으로 띄운 서버에 브라우저(Playwright)로 접속해, 한글 입력 상태처럼 글자는 자모(`ㄱ` · `ㄹ` · `ㅇ`)이고 자리는 R · F · D 인 키 입력을 보내 탄창 빼기 · 쥐기 · 꽂기 · 슬라이드와 이동이 되는 것을 확인함
