# v0.2.0

첫 공개 버전입니다. 0.1.0 초안(브라우저에서만 도는 버전)을 서버 권위 구조로 바꿨습니다.

## 달라진 점

- **직접 장전 권총.** 쏘기(클릭) · 탄창 빼기(R) · 탄창 꽂기(F) · 슬라이드 당기기(Space) · 낱개 탄 채우기(E)를 따로 합니다. 탄창 8발 + 약실 1발.
  - 탄창을 꽂아도 약실은 비어 있어서 슬라이드를 당겨야 쏠 수 있습니다. 약실이 찬 채로 당기면 한 발을 버립니다.
  - 남은 탄이 있는 탄창을 빼면 주머니 맨 뒤로 들어가고, 빈 탄창은 버립니다.
  - 장전 동작 중에는 이동이 70% 로 느려지고 다른 동작을 할 수 없습니다.
- **탄 수는 숨겨져 있습니다.** Q 를 0.6초 동안 들고 있으면 `git status` 로 약실 · 탄창 · 주머니 · 낱개 탄을 보여 줍니다.
- **5개 층 탈출.** 층마다 칸막이 벽과 책상으로 된 맵이 새로 만들어지고, 오른쪽 아래의 롤백 터미널에 닿으면 다음 층으로 갑니다. 층을 넘을 때 체력이 1 찹니다 (최대 5).
- **적.** 버그, NullPointerException(빠름), Merge Conflict(2층부터. 쓰러뜨리면 `<<<<<<< HEAD` 둘로 갈라짐). 벽 너머의 적은 보이지 않습니다.
- **휴대폰.** 왼쪽 드래그로 이동, 화면 버튼으로 쏘기 · 장전 · 점검. 조준은 가장 가까운 보이는 적으로 자동.
- **새 소식.** 타이틀 화면 오른쪽 아래의 버전을 누르면 새 소식을 볼 수 있습니다. 새 버전을 처음 볼 때는 저절로 뜹니다.

## 내부 변경

- **서버 권위** (`server/`): Node + `ws` 서버 한 프로세스가 화면 파일(`dist`), `/healthz`, WebSocket(`/ws`)을 서빙합니다.
  - 클라이언트는 입력 의도(이동 방향, 조준 각도, 쏘기, 장전 동작, 점검 중인지)만 보냅니다. 위치 · 체력 · 탄 · 처치 · 점수는 서버가 30Hz 고정 틱으로 계산합니다.
  - 층의 시드는 서버가 `crypto.randomInt` 로 정하고 클라이언트에 보내지 않습니다.
  - 스냅샷에는 플레이어가 볼 수 있는 것만 담습니다: 벽 너머(시야선이 막힌) 적과 탄은 빼고, 탄 수는 점검을 0.6초 이상 들고 있을 때만 담습니다. 총 상태는 탄창이 꽂혔는지, 주머니 탄창 개수, 낱개 탄이 있는지만 보냅니다.
  - 쏘기와 장전은 틱마다 하나씩, 총이 동작 중이면 끝날 때까지 기다렸다 처리해서 연타로 빨라지지 않습니다. 깨지 않은 층은 넘길 수 없습니다.
- **메시지 검증** (`src/shared/protocol.ts`): 256바이트 넘는 메시지, 모르는 종류, 숫자가 아닌 값, 모르는 장전 동작은 거부합니다. 범위를 넘는 값은 잘라 냅니다. 모르는 필드는 버립니다.
- **연결 제한** (`server/security.ts`, `server/index.ts`): 다른 사이트의 Origin 거부, 전체 300 · 주소당 4 연결, 연결마다 초당 60개(순간 120개) 메시지, 위반 5번이면 끊기, 응답 없는 연결 30초마다 정리. 주소는 `CLIENT_IP_HEADER`(Render 는 `cf-connecting-ip`)에서 읽습니다.
- **정적 파일**: dist 밖 경로 차단, 보안 헤더(CSP · nosniff · 프레임 금지), `assets/` 는 오래 캐시.
- **배포**: Render Blueprint(`render.yaml`, 싱가포르 무료 플랜), 문서 · 테스트만 바뀐 커밋은 다시 배포하지 않음. `main` 에 새 버전이 들어오면 태그와 GitHub 릴리즈를 만드는 워크플로(`.github/workflows/release.yml`).
- **릴리즈 절차**: 게임 안 새 소식(`src/shared/releases.ts`)과 GitHub 릴리즈 본문(`docs/releases/`)을 따로 씁니다. 버전 일치와 새 소식 규칙은 테스트가 확인합니다.
