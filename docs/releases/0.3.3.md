# v0.3.3

## 달라진 점

- **아래 레터박스.** 화면 아래에 검은 띠(화면 높이의 25%, 140~250px)를 두고, 탄창 칸 1~4 · 손 · 총 리그를 그 안에만 그립니다. 게임 화면은 띠 위쪽만 쓰므로 총과 탄창이 플레이를 가리지 않습니다. 총은 위아래로 기울여도 띠 밖으로 나가지 않게 크기를 정합니다.
- **카메라.** 방의 천장부터 바닥까지가 게임 화면에 꽉 차게 거리와 높이를 맞춥니다 (전에는 바닥 아래 빈 공간이 크게 보였습니다). 슬로모션 중에는 예전처럼 플레이어 쪽으로 다가갑니다.
- **총구 화염.** 흰 상자 모양의 화염을 없애고, 쏘는 순간 총을 따뜻하게 비추는 불빛만 남겼습니다.

## 고친 것

- 오래 하다 보면 "서버와 연결이 끊겼어요"가 떴습니다. 서버는 30초마다 연결에 확인 신호(ping)를 보내고 다음 확인 전까지 응답(pong)이 없으면 끊는데, 응답을 받는 처리를 연결을 직접 받는 방식(`handleUpgrade`)에서는 일어나지 않는 이벤트(`connection`)에 걸어 두어서, 정상 연결도 응답이 없는 것으로 보고 30~60초 뒤에 끊었습니다. 이제 연결을 받을 때 응답 처리를 직접 겁니다.
- 메시지 규칙 위반 횟수가 판 내내 쌓이기만 해서, 오래 하면 가끔 생기는 위반(순간적으로 메시지가 몰림 등)이 모여 끊길 수 있었습니다. 10초 동안 위반이 없으면 지웁니다.
- 총 리그가 화면 오른쪽 끝에 붙어 있어서 총구 쪽이 잘렸습니다. 총구 앞에 자리를 남깁니다.

## 내부 변경

- `server/index.ts`: 살아 있는지 확인하는 간격을 `PING_MS` 환경 변수로 바꿀 수 있습니다 (기본 30초, 시험용).
- `src/client/rig.ts`: 레터박스 크기에 맞춘 배치 (총 그림의 세로 가운데를 띠 가운데에). 화염 모양 코드를 지웠습니다.
- `src/client/scene.ts`: 방 높이에 맞춘 카메라 거리 · 높이.
