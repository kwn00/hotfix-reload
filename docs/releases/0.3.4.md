# v0.3.4

## 달라진 점

- **즉시 반응.** 이동 · 점프 · 숙이기가 서버의 답을 기다리지 않고 키를 누른 다음 화면 프레임에 바로 움직입니다. 전에는 서버(싱가포르)까지 다녀오는 시간에, 서버 틱 대기(최대 0.03초)와 화면 보간(0.03초)이 더해져 늦게 느껴졌습니다.
  - 판정은 그대로 서버가 합니다. 화면은 서버와 같은 이동 코드로 내 캐릭터만 먼저 움직여 보고(예측), 서버가 보낸 위치에 맞춥니다(보정). 어긋난 만큼은 0.1초 안팎에 걸쳐 부드럽게 따라갑니다.
- **조준점.** 클릭하는 순간 조준점이 벌어집니다 (탄이 나갔는지는 서버가 정합니다).

- **파비콘.** 브라우저 탭 · 즐겨찾기 · 홈 화면에 쓰는 아이콘을 넣었습니다. 게임 팔레트로 그린 16×16 픽셀 권총(어두운 둥근 바탕, 총구 끝에 초록 불빛 한 점)입니다.

## 내부 변경

- **통신 규격 4** (`PROTOCOL_VERSION` 3 → 4): 입력에 번호(`seq`)를 붙이고, 스냅샷에 서버가 처리한 마지막 번호(`ack`)와 내 세로 속도 · 땅에 닿았는지(`vy`, `ground`)를 싣습니다. 플레이어 위치는 원래 숨긴 정보가 아닙니다.
- **입력 줄** (`server/session.ts`): 화면은 서버 틱과 같은 30Hz 로 틱마다 입력 하나를 보내고, 서버는 틱마다 하나씩 꺼내 씁니다. 서버 타이머가 늦어 줄이 2개를 넘으면 오래된 입력의 이동은 건너뛰고 쏘기 · 장전 같은 일회성 동작만 살립니다 (줄이 쌓이면 그만큼 반응이 늦어지므로). 입력이 오지 않는 틱에는 마지막 입력을 이어 씁니다.
- **게임 루프** (`server/index.ts`): `setInterval` 대신 다음 틱 시각을 직접 맞추는 루프로 바꿔 30Hz 가 밀리지 않게 했습니다.
- **예측** (`src/client/predict.ts`): 이동 · 점프 · 숙이기 한 틱을 `movePlayer`(`src/shared/game.ts`)로 떼어 서버와 화면이 같은 코드를 씁니다. 쓰러짐 · 제압 중 · 끝남에는 예측을 멈추고 서버 위치를 씁니다. 화면이 느려도(프레임이 적어도) 실제 흐른 시간만큼 입력 틱을 보냅니다.

- `public/favicon.svg`(픽셀마다 사각형, `crispEdges`), `public/favicon-32.png`, `public/apple-touch-icon.png`(180px)를 더하고 `index.html` 에 연결했습니다. Vite 가 `public/` 을 `dist/` 로 그대로 복사하고, 서버는 기존 정적 파일 처리로 내보냅니다.

## 확인한 것

- 단위 테스트: 서버가 3틱 늦게 처리해도 예측이 서버 결과와 같아지는 것(걷기 · 점프 · 숙이기), 입력 즉시 예측 위치가 움직이는 것, 입력 번호 처리 · 줄 넘침 · 지연이 쌓이지 않는 것
- 왕복 150ms 로 늦춘 연결에서 키를 누른 뒤 그려지는 내 위치가 움직이기까지 3~8ms (다음 화면 프레임), 걷고 점프하는 동안 뒤로 튀는 프레임 없음

- `npm run typecheck`, `npm test`, `npm run build`
- 운영 방식으로 띄운 서버에서 세 파일이 200 과 올바른 형식(image/svg+xml, image/png)으로 내려오는 것, 16 · 32 · 180px 크기의 모양을 확인함
