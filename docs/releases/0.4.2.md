# v0.4.2

## 달라진 점

- **시야의 흐려짐.** 적과 바닥의 탄창이 시야에서 벗어나면(벽 · 책상 너머로 가거나 쓰러지거나 주웠을 때) 툭 사라지지 않고, 마지막으로 보인 자리에서 0.3초 동안 서서히 흐려집니다. 시야에 들어올 때도 0.2초 동안 서서히 나타납니다.
  - 흐려지는 동안에도 마지막으로 보인 자리에 머물러, 벽 너머에서 어디로 움직였는지는 드러나지 않습니다.
  - 적의 총 · 그림자 · 조준선은 반쯤 흐려지면 숨깁니다.

## 내부 변경

- `src/client/scene.ts`: 적과 탄창마다 보이는 정도(0~1)를 두고, 화면에 보이는 목록에서 빠지면 줄여 0 이 되면 지웁니다. 적의 몸은 그림의 빈칸을 버리는 기준(alphaTest)을 낮춰 투명도로 섞고, 탄창은 하나마다 재질을 따로 두어 흐려지게 했습니다 (지울 때 정리).

## 확인한 것

- `npm run typecheck`, `npm test`, `npm run build`
- 브라우저(Playwright)에서 적 · 탄창이 나타났다 사라지는 흐름을 오류 없이 확인함
