# v0.4.2

## 달라진 점

- **가려진 것도 흐리게 보입니다.** 벽 · 책상 너머의 적 · 탄 · 바닥 탄창도 화면에 그리고, 주인공의 시야선 밖이면 살짝 흐리게(투명도 35%) 그립니다. 전에는 시야선 밖이면 아예 그리지 않아 툭 사라졌습니다.
- 시야선에 들어오고 나갈 때 0.25초 동안 서서히 선명해지고 흐려집니다. 쓰러진 적과 주운 탄창은 그 자리에서 서서히 사라집니다.
- 흐린 적은 총과 그림자를 숨기고 몸만 그립니다. 조준선은 흐린 만큼 옅게 보입니다.

## 내부 변경

- `src/shared/protocol.ts`: 스냅샷에 살아 있는 적 · 모든 탄 · 바닥 탄창을 담고, 각각 주인공 시야선 안인지(`seen`)를 표시합니다. 총구 화염 · 맞은 자리도 모두 담습니다. 탄 수는 예전처럼 점검할 때만 담습니다.
  - 게임은 이미 브라우저에서 돌기 때문에(v0.4.0) 가려진 것을 보여 줘도 점수 검증에는 영향이 없습니다.
- `src/client/scene.ts`: 적 · 탄창마다 보이는 정도를 두고 시야선 안이면 1, 밖이면 0.35 쪽으로 0.25초에 걸쳐 옮깁니다. 적의 몸은 그림의 빈칸을 버리는 기준(alphaTest)을 낮춰 투명도로 섞고, 탄창은 하나마다 재질을 따로 둡니다(지울 때 정리). 시야선 밖의 탄은 흐린 재질로 그립니다.
- 작업 규칙(`CLAUDE.md`)의 화면 규칙을 바꿨습니다.

## 확인한 것

- `npm run typecheck`, `npm test` (스냅샷에 벽 너머 적 · 탄이 시야선 밖 표시로 담기는 테스트), `npm run build`
- 브라우저(Playwright): 두 칸 높이 책상 너머의 적 · 탄창이 흐리게, 이쪽의 적은 선명하게 그려지는 것을 확인함
