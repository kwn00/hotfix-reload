# 핫픽스 리로드 (Hotfix Reload)

> 금요일 배포가 터졌다. 권총 한 자루와 탄창 몇 개로 롤백 터미널까지.

[Friday Deploy](https://github.com/kwn00/friday-deploy) 세계관을 잇는 **직접 장전 액션** 웹 게임 초안.
자동 공격 서바이버였던 전작과 달리, 이번엔 한 발 한 발이 손에 달려 있습니다.

## 핵심: 직접 장전

| 키 | 동작 | 메모 |
| --- | --- | --- |
| 클릭 | 쏘기 | 약실이 비면 `찰칵` |
| R | 탄창 빼기 | 남은 탄이 있으면 주머니 맨 뒤로, 빈 탄창은 버림 |
| F | 탄창 꽂기 | 주머니 맨 앞 탄창. **약실은 안 채워짐** |
| Space | 슬라이드 당기기 | 약실에 탄이 있었으면 한 발 버려짐 |
| E | 낱개 탄 채우기 | 가장 덜 찬 탄창에 한 발씩 |
| Q (꾹) | `git status` | 0.6초 동안 들고 있어야 남은 탄이 보임 |

- 탄 수는 화면에 안 나옵니다. 직접 세세요 (탄창 8발 + 약실 1발).
- 장전 동작 중에는 느려지고 다른 동작을 못 합니다.
- 벽 너머의 적은 보이지 않습니다.

## 적

버그 · NullPointerException(빠름) · Merge Conflict(죽으면 `<<<<<<< HEAD` 둘로 갈라짐). 5층을 지나면 주말을 지킵니다.

## 개발

```bash
npm install
npm run dev        # 개발 서버
npm test           # 장전 · 시뮬레이션 단위 테스트
npm run build      # 타입 검사 + 빌드 (dist/)
```

- `src/gun.ts` 권총 상태 머신 (순수 로직)
- `src/game.ts` 층 생성 · 이동 · 충돌 · 적 AI (시드 기반)
- `src/main.ts` 입력 · 렌더링 (Canvas 2D) · `src/sound.ts` WebAudio 효과음

지금은 서버 없이 정적 파일만으로 돕니다. 최고 점수는 브라우저(localStorage)에만 저장됩니다.
